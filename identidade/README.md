# identidade/ — A Cara do Negócio

Esta pasta guarda todos os assets visuais e diretrizes estruturais de marca que o RrcodeOS utiliza para gerar conteúdos autônomos.

## O que colocar aqui?
- **Logotipos:** Versões em `.png`, `.svg` (com fundo transparente, variações clara/escura).
- **Referências Visuais:** Imagens que ditam o estilo da marca (moodboards).
- **Tipografia:** Arquivos de fontes (`.ttf`, `.otf`) caso a marca use algo fora do padrão Google Fonts.
- **Brandbook:** Manuais em PDF ou resumos visuais.

## Como o RrcodeOS usa isso?
A skill `/carrossel` e outras ferramentas de geração visual leem a regra `.agents/rules/design-guide.md` e buscam os assets originais diretamente desta pasta para aplicar em posts, sites expressos e materiais impressos/digitais.

*Nota: Mantenha os arquivos com nomes limpos (ex: `logo-principal.png`, `logo-branco.png`) para facilitar o vínculo com a IA.*
