# /setup-redes — O Arquiteto Social (RrcodeOS)

## Objetivo
O usuário vendeu "Gestão de Redes Sociais" mas os perfis do cliente estão abandonados ou não convertem. Esta skill "arruma a casa" (Instagram, LinkedIn, Facebook) antes do iniciante começar a gerar tráfego, garantindo credibilidade máxima.

## Fluxo de Execução

### 1. Auditoria e SEO de Perfil
Defina as redes prioritárias com base no nicho (ex: B2B = LinkedIn forte; Moda = Instagram/TikTok). Gere os fundamentos para o usuário aplicar nas contas:
- **Username / Handle:** Sugestões fáceis de buscar.
- **Bio (O Pitch de 160 caracteres):** Textos com palavras-chave do nicho (para o SEO do Instagram/LinkedIn) e chamada para ação (CTA) clara.
- **A Árvore de Links:** A estrutura do que o usuário deve configurar no Linktree/site principal.

### 2. Estrutura Visual do Perfil
Gere as instruções para a identidade visual (ou use imagens geradas via IA para dar como modelo ao usuário):
- Foto de Perfil (Logo ou foto corporativa profissional).
- Capas de LinkedIn / Facebook.
- **Estratégia de Destaques (Instagram):** Crie a lógica dos 4 a 5 balões essenciais (ex: Quem Somos, Nossos Serviços, Resultados/Depoimentos, Bastidores, Como Comprar).

### 3. Matriz de Aquecimento (Os Primeiros Posts)
Para não mandar tráfego para um perfil vazio, gere o conteúdo de fundação (Copy + Ideia Visual):
1. **O Post Bandeira:** Quem somos e o que resolvemos.
2. **O Post Autoridade:** Por que o cliente é a melhor escolha da região.
3. **O Post Prova:** Um case, depoimento ou demonstração real do serviço.

Salve tudo estruturado em `Clientes/<Nome>/redes_sociais/setup_inicial.md`.
